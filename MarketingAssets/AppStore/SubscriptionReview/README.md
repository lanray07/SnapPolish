## Folder Guide

- `ReviewScreenshots-1242x2688/` - primary review screenshots using an accepted iPhone App Store screenshot size.
- `ReviewScreenshots-640x920/` - smaller fallback screenshots for upload fields that reject full-size art.
- `PromotionalImages-1024x1024/` - square promotional images for the subscription image slot, if shown.
- `JPG-Fallbacks/` - JPG copies for upload forms that reject PNG or require smaller files.

For the Review Screenshot field, start with the `1242x2688` PNG. Use the fallback only if App Store Connect rejects the primary file.
